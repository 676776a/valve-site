# Valve Corporation — сайт-проект

Учебный одностраничный сайт о компании Valve Corporation, созданный на чистом HTML/CSS/JS.

## 🚀 Демо
https://676776a.github.io/valve-site/

## 📦 Стек
- HTML5
- CSS3 (Grid, Flexbox, анимации)
- Vanilla JavaScript (IntersectionObserver)

## 📂 Структура
- `index.html` — разметка
- `css/style.css` — стили
- `js/script.js` — интерактив
- `images/` — изображения

## 📌 Разделы
1. О компании
2. История (таймлайн 1996–2022)
3. Легендарные игры
4. Steam
5. Интересные факты
